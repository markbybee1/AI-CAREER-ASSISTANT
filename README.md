# AI Career Assistant

A beginner-friendly Python project that recommends AI career paths based on a user's interests, experience, and skills.

## About the Project

I created this project while learning Python and exploring careers in artificial intelligence.

The program asks users about their experience with Python, AI tools, coding, and data. It then uses conditional logic to recommend a potential AI career path and calculate an AI Readiness Score.

## Features

- Collects user information
- Evaluates Python and AI experience
- Recommends AI-related career paths
- Calculates an AI Readiness Score from 0–100
- Uses conditional logic to personalize results

## Technologies Used

- Python
- Google Colab
- GitHub

## Python Concepts Used

- Variables
- `input()`
- `print()`
- `if`, `elif`, and `else`
- Boolean conditions
- String methods such as `.lower()`
- Basic scoring logic

## How to Run

1. Open `AI_Career_Assistant.ipynb`
2. Click **Open in Colab**
3. Run the program
4. Answer the questions
5. View your career recommendation and AI Readiness Score
